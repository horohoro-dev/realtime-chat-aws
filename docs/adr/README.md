# ADR（設計の判断の記録）

ADR（Architecture Decision Record）は、構成や技術を選んだ理由を、1件の判断につき1つのファイルに残すものです。決めた内容だけでなく、背景、検討したほかの案、決めたことで生じる影響を書きます。

## 一覧

| 番号 | 題名 | 状態 |
|---|---|---|
| [0001](0001-realtime-websocket-elasticache.md) | リアルタイム通信を ECS 上の WebSocket と ElastiCache で行う | 決定 |

## 書き方

- ファイル名は `<4桁の番号>-<英語の短い名前>.md` にします。
- 見出しは「背景」「決定」「検討した案」「結果」の4つにします。
- 決定を変えるときは、元の ADR を書き換えずに新しい ADR を作り、元の ADR の状態を「置き換え（ADR-xxxx）」にします。
